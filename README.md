부모님·가족이 휴대폰으로 쉽게 볼 수 있도록 만든 단일 페이지 웹사이트입니다.

- **점검일**: 2026-05-09 (전문 점검 — 홈체크)
- **시공사**: DL이앤씨 (e편한세상 검단 웰카운티)
- **전체 79건** / 건설사 시스템 완료 처리 **77건** / 보수 후 사진까지 확인되는 곳 **57건**

## 보기 (배포 주소)

GitHub Pages: **https://piko9388.github.io/gumdanhaja/**

> 위 주소는 GitHub Pages를 켠 뒤(아래 "배포 방법") 1~2분이면 열립니다.

## 화면 구성

- **홈** — 인사말 + 진행 상황 요약
  - 통계 3분할: 전체 79 / 사진으로 확인됨 57 / 사진 준비중 22
  - 비교 막대: **건설사 완료 처리 77곳 → 사진으로 확인 가능 57곳** (한눈에)
  - "보수 완료된 곳" / "사진 준비 중인 곳" 두 섹션의 카드 목록
- **상세** — 카드를 누르면
  - 보수 완료: **보수 전 ⬇ 보수 후** 사진을 세로로 비교
  - 사진 준비중: 현재 사진 + 안내 문구
  - 사진을 누르면 전체화면 확대

부모님 가독성을 위해 본문 글자 21px, 어려운 용어 없이 "보수 완료 / 사진 준비중"으로만 표현했습니다.

## 파일 구조

| 파일 | 설명 |
|------|------|
| `index.html` | 메인 페이지 (디자인 + 동작 전부 포함) |
| `data.js` | 하자 데이터 79건 (`ITEMS`, `STATS`) |
| `images/` | 보수 전/후 사진 — `images/{등록번호}/before_*.jpg`, `after_*.jpg` |
| `.nojekyll` | GitHub Pages가 폴더를 그대로 서빙하도록 하는 표시 파일 |

> ⚠️ `images/` 폴더(사진 218장)는 별도로 추가해야 사진이 보입니다. (저장소에 아직 없으면 사진이 깨져 보입니다.)

## 배포 방법 (GitHub Pages)

1. 이 저장소에 코드와 `images/` 폴더가 모두 올라간 상태에서
2. **Settings → Pages**
3. **Source**: `Deploy from a branch`
4. **Branch**: `main` / 폴더 `/ (root)` → **Save**
5. 1~2분 뒤 `https://piko9388.github.io/gumdanhaja/` 접속

## 데이터 출처

DL이앤씨 모바일 AS 시스템(`mobileas.dlenc.co.kr`)에 등록된 하자 79건을
등록번호(sysno)별로 수집하여 정리했습니다. 보수 전 사진은 점검일(2026-05-10) 기준,
보수 후 사진은 작업일 폴더 날짜 기준으로 자동 분류했습니다.
